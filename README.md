# TABS V2 FS

TABS V2 FS is a userscript for simulating combat before attacking in
Command & Conquer: Tiberium Alliances. It includes community contributions and
optimizations for AwSim, UI modifications, and an integrated formation saver.

## Install

1. Install a userscript manager in your browser, such as Tampermonkey or
   Violentmonkey.
2. Open [`TABS_V2_FS.user.js`](./TABS_V2_FS.user.js) from this repository and
   choose your userscript manager's install option.
3. Visit a supported Command & Conquer: Tiberium Alliances game page.

The script is configured to run on `alliances.commandandconquer.com` pages.
